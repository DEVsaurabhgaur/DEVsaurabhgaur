## About

Most engineers work at the implementation layer.  
I work one level above — designing **evaluation architecture** that defines what intelligent means, then building the systems that run on those criteria.

- **Frontier Model Evaluation** — adversarial frameworks that expose failure modes standard benchmarks miss; outputs route into RLHF training pipelines
- **Agentic Systems** — LangGraph · LangChain multi-agent workflows with tool-use chains, memory persistence, and context routing under real-world constraint
- **RAG Infrastructure** — FAISS · Chroma · production retrieval pipelines built for scale, not demos
- **Full-Stack AI Products** — Python · TypeScript · React · Next.js · Supabase → ideas become deployed tools
- **Creative Technologist** — 200+ piece AI art portfolio at [saurabhgaur.world](https://saurabhgaur.world) · Stable Diffusion · Midjourney
